C1/C2 Forwarding Test Results — 16-Bit Encoding @ 4.0 MHz
==========================================================
Setup: Pi → SN74AHCT125N → PCB1 → PCB2 → PCB3 → PCB4
SPI speed: 4.0 MHz (Section 4: 2.0 MHz), 10kΩ pull-up on GPIO 20

16-bit encoding: 2 SPI bytes per data bit
  Logic 0: 0x1F + 0xFF → 750ns LOW (spec: 620-820ns)
  Logic 1: 0x03 + 0xFF → 1500ns LOW (spec: 1300-2000ns)
  Period: 4µs = 250 KHz (spec: 200-400 KHz)
  LOW pulse entirely in byte 1, byte 2 always 0xFF.
  Inter-byte gaps ONLY at HIGH→HIGH transitions.

Reset: 125 bytes = 250µs (spec: >= 200µs)
C2 = bitwise NOT of C1 (validated by script)

For each test, record what you see on PCB1 and PCBs 2-4.
"cycling" = demo mode color preset cycle.
