C1/C2 Forwarding Test Results — led_c1c2_test.py (v2)
=====================================================
Setup: Pi → SN74AHCT125N → PCB1 → PCB2 → PCB3 → PCB4
10kΩ pull-up on GPIO 20 to 3.3V

For each test, record what you see on PCB1 and PCBs 2-4.
Note: "cycling" = demo mode color preset cycle.
      "responding" = showing commanded color (not cycling).

Key hypothesis: At 2.0 MHz, logic 0 LOW = 500ns (below 620ns spec).
At 1.6 MHz, logic 0 LOW = 625ns (within 620-820ns spec).
Forwarding may only work when timing is within spec.
